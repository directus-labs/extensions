These extensions are no longer maintained. They get no bug fixes, dependency updates, or support for new Directus versions. Installs that still use them keep working, but npm shows a deprecation warning.

The source stays here for now so you can fork it. We will remove it from `main` later. When we do, the folder links below will be swapped for permanent links to the last commit that had the code, so it stays easy to find.
